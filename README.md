# DJI Web Flight Simulator

Однофайловый браузерный симулятор полёта на Three.js. Запускается локально открытием `index.html` в современном браузере; интернет нужен только для загрузки Three.js с CDN.

## Запуск
1. Откройте [index.html](./index.html) или скачайте файл и откройте его в Chrome / Edge / Firefox.
2. Разрешите звук после первого взаимодействия со страницей.
3. Подключите геймпад до открытия страницы. Если калибровка не появилась автоматически, откройте **Настройки → Перекалибровать геймпад**.
4. Выберите модель и сцену в главном меню, затем нажмите «Продолжить полёт».

## Управление
- Клавиатура: W/S — тангаж, A/D — крен, Q/E — yaw, Space/Shift — высота, V — камера, M — миникарта, R — запись, B — удержание для взлёта / короткое нажатие для посадки, X — удержание RTH.
- Геймпад: левый стик — yaw/высота, правый — pitch/roll; B — взлёт/посадка, X — RTH, RT/LT — аналоговый наклон подвеса, LB/RB — режим, Y — фото, A — двойное нажатие для аварийной остановки, Start — настройки, Select — миникарта, D-pad — подвес/зум.
- Индексы кнопок и осей Gamepad API зависят от модели геймпада и браузера. Стандартная раскладка рассчитана на типичный mapping `standard`.

## Настройки
В настройках доступны высотный и дальностный лимиты, датчики столкновений, deadzone стиков и триггеров, чувствительность, кривые отклика, сглаживание подвеса и триггеров, язык и включение/выключение голосовых сообщений, качество графики и тени. Настройки сохраняются в `localStorage`. Калибровка осей и триггеров хранится отдельно в `localStorage`.

## Возможности
- Пять профилей аппаратов, три режима управления и три сцены.
- Модель движения с инерцией, сопротивлением, ветром, ограничениями скорости и высоты.
- Датчики препятствий, RTH по промежуточным точкам, HUD, миникарта и след полёта.
- QuickShots, FocusTrack, подвес, зум, фото, WebM-запись canvas и синтез речи.
- Клавиатура и Gamepad API работают параллельно.

## Важные ограничения текущей версии
Это самостоятельная игровая симуляция, а не сертифицированный тренажёр DJI и не точная копия DJI Fly. Геометрия сцен процедурная и low-poly; модели аэродинамики, батареи, датчиков, препятствий и маршрутизации упрощены для браузерной производительности. RTH использует эвристический поиск безопасных промежуточных точек, а не полноценный навигационный планировщик. ActiveTrack/QuickShots — игровые траектории относительно тестовых целей, не компьютерное зрение. Поддержка аналоговых триггеров зависит от того, как браузер отображает их в Gamepad API. Для стабильной записи и звука рекомендуется запускать страницу по HTTPS или localhost; для простого запуска сервер не требуется.

## Производительность
В настройках можно выбрать low/medium/high и отключить тени. Фактический FPS зависит от GPU, браузера, разрешения и числа объектов. Гарантировать 60 FPS на любом среднем ПК невозможно.
